## Items decided

### SUB-2026-006 PartnerHub API gateway for wholesale partners (G2, Tier 2 (Standard))

Decision: **Approved with conditions**.

The submission showed a conflict between STD-API-004 R6 and STD-SEC-002 R7. The Chair ruled that STD-API-004 is the more specific standard for API design, so mutual TLS bound tokens apply to every new API. Existing partners are covered by a time-limited dispensation.

Conditions:

- C1: Migrate wave 1 of partners to mutual TLS. Owner Wholesale Integration Lead, due 2026-09-30.
- C2: Migrate wave 2 of partners to mutual TLS. Owner Wholesale Integration Lead, due 2026-11-30.
- C3: Migrate wave 3 of partners to mutual TLS. Owner Wholesale Integration Lead, due 2026-12-31.

Dispensation granted: DISP-2026-004.
