# SUB-2026-008 Workday HR integration

## Summary

Integrate the Workday HR system with payroll, identity, and the learning platform.

Sponsor: CHRO. Lead architect: Lena Fischer. Request type: SaaS onboarding. Tier 2 (Standard). Data classification: Confidential. Service tier: Tier 3. Estimated cost: 0.7 million US dollars.

## Architecture

- Workday events published to the managed Kafka platform through the vendor's integration cloud.
- Identity provisioning through SCIM into the corporate identity provider.
- Payroll file transfers move to the managed file transfer service.

## Non-functional requirements

Availability per vendor 99.7 percent. Daily payroll cut-off 18:00.
