# SUB-2026-003 EdgeSense 5G edge analytics

## Summary

Analytics software on 5G edge nodes that detects congestion and quality problems within seconds and sends summaries to the central data platform.

Sponsor: VP Network Technology. Lead architect: Marcus Oyelaran. Request type: New system or platform. Tier 2 (Standard). Data classification: Confidential. Service tier: Tier 2. Estimated cost: 1.6 million US dollars.

## Architecture

- Containerised analytics on 38 edge nodes in regional data centres.
- Each node keeps raw logs locally. Summaries and security events are forwarded to the central platform.
- Infrastructure is provisioned by code and managed by the central platform team.
- Edge nodes have 2 terabytes of local storage.

## Non-functional requirements

Detection within 5 seconds. Availability 99.5 percent per node. Recovery time 4 hours.

## Options considered

- **Ship all logs to the central platform.** Meets the standard but needs about 11 terabytes a month of backhaul. Rejected on cost.
- **Keep raw logs 30 days at the edge and forward security events.** Fits the node storage and keeps the audit trail. Recommended.

## Decisions

### G2: Approved with conditions

Complete: 2026-04-28. Decided: 2026-05-12. Paused: 0 business days.

## Discussion and rationale

The board accepted a shorter local retention for raw logs provided the security events reach the central platform quickly. The Data Architect noted that a renewal would be needed if the edge storage was not expanded.
