# SUB-2026-014 Sales enablement knowledge assistant

## Summary

An internal assistant that answers sales questions from product sheets, pricing guides, and win-loss notes held in SharePoint.

Sponsor: VP Enterprise Sales. Lead architect: Aiko Tanaka. Request type: Generative AI use case (internal users only). Tier 2 (Standard). Data classification: Confidential. Service tier: Tier 4. Estimated cost: 0.4 million US dollars.

## Architecture

- Retrieval-augmented generation over selected SharePoint sites using Azure OpenAI Service inside the Meridian tenancy.
- Retrieval is expected to respect SharePoint permissions.
- Answers show their sources.

## Non-functional requirements

300 users. Median answer time under 6 seconds.

## Standards compliance matrix

| Requirement | Status | Note |
|---|---|---|
| STD-AI-007 R2 | Met | Azure OpenAI Service inside the tenancy. |
| STD-AI-007 R8 | Open | Permission trimming is assumed but not yet demonstrated. |

## Options considered

- **Public chat tool with pasted documents.** Rejected under STD-AI-007 R3.
- **Internal retrieval assistant.** Recommended.

## Decisions

### G1: Proceed

Complete: 2026-07-21. Decided: 2026-08-04. Paused: 0 business days.

## Discussion and rationale

The board approved the concept and asked for permission trimming to be proven in the design review before any build.
