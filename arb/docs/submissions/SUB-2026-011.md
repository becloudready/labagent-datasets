# SUB-2026-011 Mediation batch offload from the mainframe

## Summary

Move the nightly usage mediation batch from the mainframe to the cloud while keeping the existing nightly file feeds to billing.

Sponsor: VP Network Operations. Lead architect: Marcus Oyelaran. Request type: Major change to an existing system. Tier 2 (Standard). Data classification: Confidential. Service tier: Tier 2. Estimated cost: 1.9 million US dollars.

## Architecture

- Batch jobs on a managed container platform replace the mainframe jobs.
- Nightly files are delivered to billing through the managed file transfer service.
- The batch window is 02:00 to 05:00.

## Non-functional requirements

Batch completes within 3 hours. Recovery time 4 hours.

## Standards compliance matrix

| Requirement | Status | Note |
|---|---|---|
| STD-INT-009 R1 | Deviation | Remains a nightly batch, not event driven. Dispensation DISP-2026-006 requested. |
| STD-RES-005 R4 | Deviation | No recovery runbook in the first submission. |
| STD-INT-009 R5 | Met | Managed file transfer. |

## Options considered

- **Event-driven redesign now.** Delays the mainframe exit by 18 months.
- **Lift the batch first, move to events in a second phase.** Recommended.

## Decisions

### G2: Deferred

Complete: 2026-07-14. Decided: 2026-07-28. Paused: 0 business days.

### G2: Approved with conditions

Complete: 2026-08-25. Decided: 2026-09-08. Paused: 0 business days.

## Discussion and rationale

First review: deferred because there was no recovery runbook and no evidence that the batch fits the window. The team returned with both. The board approved with a dispensation for the batch pattern and a roadmap to events.
