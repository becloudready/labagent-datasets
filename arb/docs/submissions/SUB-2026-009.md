# SUB-2026-009 NetGraph network inventory graph

## Summary

A graph database that models the network, services, and the customers that depend on them, so operations can see the customer impact of a fault.

Sponsor: VP Network Operations. Lead architect: Marcus Oyelaran. Request type: New system or platform. Tier 2 (Standard). Data classification: Restricted. Service tier: Tier 2. Estimated cost: 1.1 million US dollars.

## Architecture

- Managed graph database in us-east-1 with a standby in us-west-2.
- Topology loaded nightly from the network inventory and in near real time from fault events.
- Service addresses of customers are stored, which makes the data Restricted.

## Non-functional requirements

Impact query under 2 seconds. Recovery time 4 hours.

## Options considered

- **Synthetic topology only.** Misses real-world fault patterns. Rejected.
- **Unmasked topology in a restricted test environment for six engineers.** Short-term compensating control. Recommended.

The board accepted a time-limited use of real data in test with a named group and a firm date for masking.
