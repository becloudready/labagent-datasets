# SUB-2026-006 PartnerHub API gateway for wholesale partners

## Summary

Move 14 wholesale partners from point-to-point integrations to a managed API gateway with a developer portal.

Sponsor: VP Wholesale. Lead architect: Lena Fischer. Request type: Major change to an existing system. Tier 2 (Standard). Data classification: Confidential. Service tier: Tier 2. Estimated cost: 1.2 million US dollars.

## Architecture

- Partner APIs published on the enterprise API gateway with the W2 web application firewall profile.
- New partners authenticate with OAuth 2.0 client credentials.
- Existing partners keep their current bearer tokens during migration.
- Usage analytics per partner.

## Non-functional requirements

400 requests per second peak. Availability 99.9 percent.

## Standards compliance matrix

| Requirement | Status | Note |
|---|---|---|
| STD-API-004 R6 | Conflict | Requires mutual TLS bound tokens. |
| STD-SEC-002 R7 | Conflict | Allows bearer tokens behind the W2 profile, with mutual TLS optional. |
| STD-API-004 R3 | Met | Gateway publication. |
| STD-API-004 R9 | Met | Problem details errors. |

## Options considered

- **Move all partners to mutual TLS at once.** Meets STD-API-004 but 14 partners cannot change before Q4.
- **New APIs use mutual TLS, existing partners migrate in three waves.** Meets the standard for all new work. Recommended.

## Decisions

### G2: Approved with conditions

Complete: 2026-05-26. Decided: 2026-06-09. Paused: 0 business days.

## Discussion and rationale

The submission showed a conflict between STD-API-004 R6 and STD-SEC-002 R7. The Chair ruled that STD-API-004 is the more specific standard for API design, so mutual TLS bound tokens apply to every new API. Existing partners are covered by a time-limited dispensation.
